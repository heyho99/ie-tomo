# 家トモ

家で勉強する人のとなりで見守り、ときどき声をかける AI の先生。

## 動かす

Node.js 24 以上と、GCP のプロジェクト（Firebase を追加したもの）がいる。

1. `npm install`
2. Firebase コンソールで Web アプリを追加し、Authentication の「メール / パスワード」をオンにして、使う人のユーザーを作る（新規登録は画面からはできない）
3. `client/.env.example` を `client/.env` に写し、`firebase apps:sdkconfig WEB --project <プロジェクト ID>` で出る値を書く
4. `server/.env.example` を `server/.env` に写し、AI の認証と `ADMIN_UIDS`（AI の設定を使えるユーザーの UID）を書く
5. `npm run dev` で http://localhost:5173 を開く（サーバーは 3001 番。MediaPipe のモデルは初回に自動でダウンロードされる）

テストは `npm test`。

## デプロイ

サーバーは Cloud Run、画面は Firebase Hosting に置く。`gcloud`・`firebase` の CLI にログインしておき、`gcloud config set project <ID>` でプロジェクトを決めてから：

- `./deploy.sh setup`：初回だけ（API の有効化・Firestore・サービスアカウント・TTL・ルール）
- `./deploy.sh all`：サーバー → 画面（`server/.env` の `ADMIN_UIDS` と `client/.env` を使う）
- `./deploy.sh idle`：常時起動をやめる（min-instances=0）

## 声かけのきっかけ

合図を出すかどうかはプログラムのルールで決め、何を言うかは AI が考える（定型のものを除く）。数値は既定値で、管理者設定で変えられる。

| 分類 | きっかけ | 条件 | 話す内容 |
|---|---|---|---|
| 最初 | 新しい回を開いた | — | 「（あいさつ）今日は何を勉強するんですか？」（定型） |
| 最初 | 続きから開いた | — | 「（あいさつ）前回は何をしていたんでしたっけ？」（定型） |
| 困りごと（顔） | 眠そう | 目を閉じたまま3秒（クールタイム 1分） | AI が考える |
| 困りごと（顔） | 下を向いている | 20秒続く。手元ノートがオンなら、ノートに変化がないときだけ（クールタイム 1分） | AI が考える |
| 困りごと（ノート） | 読み取れない | 判定ごと | AI が考える |
| 困りごと（ノート） | 手が止まっている | 3回続く（約1分30秒） | AI が考える |
| 興味 | 回復 | 困りごとの合図（手が止まっている・下を向いている・眠そう）のあとで、また進みはじめた | さりげなく気づく |
| 興味 | 節目 | 勉強を始めて15分ごと（15・30・45…分） | 集中していることに感心する |
| 興味 | しばらく話していない | 60〜120秒（ランダム）話していない | 内容に興味をもって質問・感想 |
| タイマー | 時間になった | 家トモが計っていた時間・ポモドーロの切りかわり | AI が考える |
| 続けるかの確認 | 勉強を続けて27分 | 一時中断する時刻（はじめは30分）の3分前。続けると答えたら一時中断する時刻を30分のばし、続けないと答えた・3分返事がなければ一時中断。残りの時間は学習画面の「勉強した時間」のバーに出す。デバッグ授業では30秒で一時中断し、その10秒前にたずねる（`client/src/continueCheck.ts`） | 続けるかたずねる |
| お知らせ | 会話が長くなった | 入力がコンテキストウィンドウの80%をこえた | 「そろそろ会話の量が増えてきたから、古い内容は要約していくね。」（定型） |

- 最初の（あいさつ）は日本時間で、4〜10時台「おはようございます。」、11〜17時台「こんにちは。」、それ以外「こんばんは。」
- 興味の合図（回復・節目・しばらく話していない）は、管理者設定でそれぞれオン・オフと間隔を変えられる。回復だけはクールタイム（既定60秒）があり、どの合図・続けるかの確認のあとも、この秒数は出さない。同時に条件を満たしたら 困りごと ＞ 回復 ＞ 節目 ＞ 興味 の上だけ出す
- 家トモが話している・返事を考え中・一時中断中は出さない

## 家トモが使えるツール

管理者設定でツールごとにオン・オフでき、AI に渡す説明も変えられる。中身は `server/src/tools/`。

| ツール | できること |
|---|---|
| `look_at_screen` | 生徒が共有している画面（教材など）を見る。画面に書き込んだ線や印も見える |
| `look_at_note` | 手元のノート（手元カメラか iPad）を見る |
| `timer` | 時間を計る（タイマー・ストップウォッチ・ポモドーロ）。始める・確かめる・やめる |
| `pause_study` | 一時中断する（続けない・休むと言われたとき）。続けるかの確認に続けると答えたら、続けることを伝える |
| `how_to_start` | 生徒に「何から始めればいい？」と聞かれたら、勉強のしかたごとの始め方（画面共有・iPad のノート・会話）を案内する |
| `what_can_you_do` | 生徒に「何ができるの？」と聞かれたら、いまオンのツールの一覧を調べて説明する |
